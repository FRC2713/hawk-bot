# Quick Pulse's mood scale and Needs Help flag are Block Kit elements, not reactions

Quick Pulse originally mirrored the Event Check-in Post: pre-populated emoji reactions (😞😕😐🙂😄 for mood, ⁉️ for Needs Help) that a student taps to answer. We moved both off reactions.

The mood scale had the same problem Deep Check-in's questions had (see ADR-0015): Slack doesn't stop someone reacting with more than one of the five mood emoji, and only a live reaction-event listener could resolve that into a meaningful "which one counts." `radio_buttons` solves it natively — single-selection enforced by Slack itself, no listener needed, consistent with how Deep Check-in already works.

Needs Help didn't have that ambiguity — it's a single independent flag, not a scale, so there was nothing technically wrong with leaving it as a reaction. We moved it anyway, to a single `checkboxes` element, for consistency: once the mood scale is Block Kit, mixing "tap a radio circle" with "add an emoji reaction" in the same message is two different interaction models for no real reason. A `checkboxes` element (confirmed to work in regular posted messages, not just modals) was chosen over a `radio_buttons` Yes/No pair specifically because it doesn't force a choice — checking it is opt-in, same as reacting is today, whereas a Yes/No pair would present every student with an explicit decision to make every time, cutting against the deliberately low-pressure tone the rest of this feature was designed around (see the Needs Help emoji change and its message copy).

The optional follow-up note is unaffected by any of this — Slack's `plain_text_input` element only works inside modals (confirmed against Slack's docs), so an in-message "short answer" field was never on the table without reintroducing a modal, which was already rejected for Deep Check-in's delivery (see ADR-0015's rejection of a gated conversation, and the modal-vs-DM-sequence decision it followed from). The note stays exactly what it already was: a plain DM reply in the same conversation, no Block Kit involved.
